Легковесный, бесшумный и надежный менеджер мульти-аккаунтов и монитор квот для **Google Antigravity** под Windows.

---

## Обзор

При активной разработке и парном программировании с агентами в Google Antigravity пользователи регулярно сталкиваются с исчерпанием лимитов на скользящее 5-часовое окно запросов или недельный объём квоты.

**Gemini Switcher** незаметно работает в системном трее Windows, непрерывно отслеживая остаток лимитов в реальном времени. Как только активная сессия приближается к заданному порогу (например, остается 5% квоты), Gemini Switcher автоматически и бесшовно переключается на следующий готовый аккаунт из вашего локального пула — без прерывания работы, без всплывающих консольных окон и без необходимости вручную копировать токены.

---

## Ключевые возможности

- **Локальный пул мульти-аккаунтов**: Сохранение авторизованной сессии Antigravity в один клик. Хранение любого количества аккаунтов, назначение читаемых псевдонимов (`Личный`, `Рабочий`, `Dev`), установка приоритетов и возможность временной приостановки (паузы).
- **Непрерывный мониторинг лимитов**: Фоновое отслеживание остатка квот и времени до сброса как для **5-часового скользящего окна**, так и для **недельного лимита**.
- **Интеллектуальная авто-ротация**: При исчерпании лимита текущего профиля утилита самостоятельно выбирает наиболее подходящий аккаунт из пула на основе приоритета, доступного остатка и времени восстановления.
- **100% бесшумная работа в фоне**: Запросы квот выполняются в изолированной песочнице с флагами `CREATE_NO_WINDOW` и очищенным окружением. Консольные окна и терминалы командной строки не всплывают и не мерцают.
- **Динамическая индикация в системном трее**:
  - 🟢 **Зеленый**: Текущая квота в норме (> 20%), автопереключение активно.
  - 🟡 **Желтый**: Предупреждение (остаток <= 20% либо активный аккаунт не сохранен в пуле).
  - 🔴 **Красный**: Критический уровень (квота исчерпана <= 5%).
  - ⚪ **Серый**: Автопереключение выключено или на паузе.
- **Нативная панель управления в темной теме**: Написана на чистом Go с использованием стандартных Win32/GDI элементов (библиотека Walk) — современный минималистичный интерфейс, никакой нагрузки от Electron/Chromium и потребление менее 25 МБ оперативной памяти.
- **Локальная безопасность и приватность**: Все данные хранятся исключительно на вашем компьютере (`%USERPROFILE%\.gemini-switcher\`) и взаимодействуют напрямую с системным диспетчером учетных данных Windows (`gemini:antigravity`). Никакой телеметрии, облачных релеев и сторонних серверов.
- **Мгновенный перезапуск Language Server**: При смене сессии утилита автоматически отправляет сигнал на перезапуск языкового сервера Antigravity (`language_server.exe`), благодаря чему редактор подхватывает новые учетные данные на лету без ручного перезапуска IDE.
- **Многоязычный интерфейс**: Полная локализация на русский, английский, немецкий, польский и украинский языки с автоопределением языка Windows.
- **Удобный инсталлятор и портативный режим**: Доступна как в виде автономного `.exe`, так и в виде установщика `Gemini-Switcher-Setup.exe` с автозапуском и ярлыками.

## Архитектура и принцип работы

```
┌────────────────────────────────────────────────────────┐
│                   Gemini Switcher                      │
│   (Системный трей + Панель управления Win32 / Walk)   │
└───────────────┬────────────────────────┬───────────────┘
                │                        │
       1. Опрос квот             2. Ротация сессий
                │                        │
                ▼                        ▼
┌───────────────────────────────┐ ┌───────────────────────────────┐
│     Изолированная песочница   │ │ Диспетчер учетных данных Win  │
│  agy -p /quota --output-format│ │     Цель: gemini:antigravity  │
│  CREATE_NO_WINDOW (Бесшумно)  │ │              +                │
│  Очищенный PATH и окружение   │ │  Antigravity app_storage.json │
└───────────────────────────────┘ └──────────────┬────────────────┘
                                                 │
                                         3. Обновление IDE
                                                 │
                                                 ▼
                                  ┌───────────────────────────────┐
                                  │ Перезапуск language_server.exe│
                                  │ Мгновенная смена токена в IDE │
                                  └───────────────────────────────┘
```

1. **Управление сессиями**: Приложение обращается к `advapi32.dll` (`CredReadW` / `CredWriteW`) по системному идентификатору `gemini:antigravity`, а также обновляет текущее имя пользователя в `%APPDATA%\Antigravity\app_storage.json`.
2. **Бесшумный сбор метрик**: Опрашивает `agy.exe --output-format json -p /quota` во временном изолированном каталоге с отключенным автообновлением (`AGY_CLI_DISABLE_AUTO_UPDATE=true`), исключая конфликты файловых блокировок.
3. **Алгоритм выбора аккаунта**: Профили, находящиеся в периоде восстановления (остаток ниже порога и время сброса еще не наступило), пропускаются. Учитывается пользовательский приоритет; при равенстве приоритетов выбирается профиль с максимальным остатком 5-часовой квоты.
4. **Контроль единственного экземпляра**: Использует именованный мьютекс Windows `Local\GeminiSwitcherSingleInstanceMutex` и событие `Local\GeminiSwitcherOpenEvent`. Повторный запуск исполняемого файла не создает дубликатов, а активирует уже открытое окно.

## Установка

### Вариант 1: Установщик Windows (Рекомендуется)

1. Скачайте `Gemini-Switcher-Setup.exe` со страницы [GitHub Releases](https://github.com/mayskiiyy/gemini-switcher/releases).
2. Запустите мастер установки:
   - Приложение устанавливается в `%LOCALAPPDATA%\Programs\Gemini Switcher`.
   - Создаются ярлыки в меню «Пуск» и на Рабочем столе.
   - Настраивается автозапуск с Windows (запуск в трее с флагом `--autostart`).
   - Добавляется запись в раздел **Параметры Windows -> Установленные приложения** с возможностью чистого удаления через `uninstall.exe`.

### Вариант 2: Портативная версия (Portable)

1. Скачайте `gemini-switcher.exe` со страницы [GitHub Releases](https://github.com/mayskiiyy/gemini-switcher/releases).
2. Поместите файл в любую папку (например, `C:\Tools\GeminiSwitcher\`).
3. Запустите `gemini-switcher.exe`. Конфигурация и база аккаунтов будут сохранены в `%USERPROFILE%\.gemini-switcher\`.

## Быстрый старт

### Шаг 1: Запуск приложения
Запустите `gemini-switcher.exe`. Откроется Панель управления, а в системном трее появится значок утилиты.

### Шаг 2: Добавление первого аккаунта
1. Откройте Google Antigravity и войдите в свой первый Google-аккаунт (например, `personal@example.com`).
2. В окне Gemini Switcher нажмите кнопку **Захватить сессию** (или кликните правой кнопкой мыши по значку в трее и выберите **Захватить текущую сессию в пул**).
3. Аккаунт появится в списке с текущими показателями квот.
4. *(Опционально)* Выделите аккаунт, нажмите **Имя аккаунта** и укажите понятное имя (например, `Личный`).

### Шаг 3: Добавление остальных аккаунтов
1. В Google Antigravity выйдите из учетной записи и авторизуйтесь под вторым аккаунтом (например, `work@example.com`).
2. В окне Gemini Switcher снова нажмите **Захватить сессию**.
3. Повторите операцию для остальных профилей (например, `developer@example.com`).

### Шаг 4: Бесперебойная работа
Теперь окно панели управления можно закрыть — программа останется в трее и будет опрашивать квоты каждые 60 секунд. При исчерпании лимита текущей сессии ротация произойдет автоматически!

## Режимы переключения

### 1. Автоматическая ротация (Auto-Switch)
- Включена по умолчанию (**Настройки** -> **Автопереключение**).
- Проверяет статус квот с заданным интервалом (`check_interval_seconds: 60`).
- При падении остатка 5-часовой или недельной квоты ниже порога (`threshold_5h: 0.05` / `threshold_weekly: 0.05`):
  1. Выбирается наиболее оптимальный готовый аккаунт не на паузе.
  2. Новые учетные данные записываются в диспетчер Windows.
  3. Перезапускается `language_server.exe` для мгновенного применения.
  4. Отправляется уведомление Windows о смене сессии.

### 2. Ручное переключение
- **Через Панель управления**: Выберите аккаунт в списке и нажмите **Переключить**.
- **Через меню трея**: Кликните правой кнопкой мыши по иконке в трее и выберите нужный аккаунт:
  - `✓ work@example.com [5ч: 92%, Нед: 88%]` (Активен)
  - `○ personal@example.com [5ч: 15%, Нед: 70%]` (Клик для активации)
  - `○ developer@example.com [5ч: сброс в 14:30 (~42m)]` (На восстановлении)

## Настройки и конфигурация

Параметры можно настроить через диалог **Настройки** в панели управления либо вручную в файле `%USERPROFILE%\.gemini-switcher\config.json`:

```json
{
  "language": "auto",
  "auto_switch_enabled": true,
  "check_interval_seconds": 60,
  "threshold_5h": 0.05,
  "threshold_weekly": 0.05,
  "notify_on_switch": true,
  "notify_mode": "all"
}
```

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `language` | string | `"auto"` | Язык интерфейса: `"auto"` (системный язык Windows), `"ru"`, `"en"`, `"de"`, `"pl"`, `"uk"`. |
| `auto_switch_enabled` | bool | `true` | Включение/выключение автоматической ротации при исчерпании лимитов. |
| `check_interval_seconds` | int | `60` | Интервал фоновой проверки квот в секундах. |
| `threshold_5h` | float | `0.05` | Порог остатка 5-часовой квоты для ротации: `0.01` (1%), `0.05` (5%), `0.10` (10%). |
| `threshold_weekly` | float | `0.05` | Порог остатка недельной квоты для ротации: `0.01` (1%), `0.05` (5%), `0.10` (10%). |
| `notify_on_switch` | bool | `true` | Отображение системных всплывающих уведомлений Windows. |
| `notify_mode` | string | `"all"` | Детализация уведомлений: `"all"` (все события), `"switch_only"` (только ротация), `"none"` (тихий режим). |

## Хранение данных и безопасность

Все рабочие файлы утилиты располагаются локально в директории `%USERPROFILE%\.gemini-switcher\`:

- `accounts.json`: База аккаунтов, данные о квотах, метки времени сброса, имена и зашифрованные токены сессий.
- `accounts.json.bak`: Автоматическая резервная копия, создаваемая перед изменением пула.
- `config.json`: Файл пользовательских настроек программы.

> [!WARNING]
> Файл `accounts.json` содержит авторизационные данные ваших сессий Google. Никогда не публикуйте, не передавайте и не загружайте этот файл в открытый доступ. Убедитесь, что каталог `.gemini-switcher` не синхронизируется в публичные облачные папки. Подробнее см. в [SECURITY.md](SECURITY.md).

## Сборка из исходников

### Требования
- **Windows 10 / 11 x64**
- **Go 1.22+** ([golang.org](https://go.dev/dl/))
- **PowerShell 5.1+**
- Утилита **Antigravity CLI (`agy`)**, установленная и доступная в переменной окружения `PATH`

### 1. Сборка исполняемого файла
Запустите скрипт сборки в PowerShell:

```powershell
.\build.ps1
```

Скрипт автоматически:
1. Загружает инструмент компиляции ресурсов Windows (`github.com/akavel/rsrc`).
2. Генерирует манифест приложения и иконки в файл `rsrc_windows_amd64.syso`.
3. Компилирует оптимизированный бинарный файл без отладочных символов и без консольного окна:
   ```powershell
   go build -trimpath -ldflags '-s -w -H windowsgui' -o gemini-switcher.exe .
   ```

### 2. Сборка инсталлятора
Для создания полноценного установщика выполните:

```powershell
.\build-installer.ps1
```

Скрипт скомпилирует приложение, упакует его со сжатием Gzip в `cmd/installer/payload.dat`, скомпилирует модуль инсталлятора и сохранит файл `Gemini-Switcher-Setup.exe` на вашем Рабочем столе.

### 3. Запуск тестов
```powershell
go test ./...
```

## Решение проблем (FAQ)

### Ошибка при обновлении квоты: `agy execution failed`
- Убедитесь, что утилита `agy.exe` установлена и доступна в системной переменной `PATH` либо по стандартным путям (`%LOCALAPPDATA%\agy\bin\agy.exe` или `%LOCALAPPDATA%\Programs\Antigravity\bin\agy.exe`).
- Проверьте вручную выполнение команды `agy --output-format json -p /quota` в PowerShell.

### Ошибка захвата сессии: `CredReadW failed`
- Убедитесь, что вы авторизованы в приложении Google Antigravity.
- Откройте Antigravity и проверьте, что сессия активна.

### Antigravity не переключает аккаунт сразу
- Gemini Switcher автоматически перезапускает `language_server.exe` во время переключения.
- Если IDE не отобразила смену в течение 5 секунд, перезагрузите окно редактора (`Ctrl+Shift+P` -> `Developer: Reload Window`).

### Полное удаление программы
- Если программа устанавливалась через инсталлятор: откройте **Параметры Windows** -> **Приложения** -> **Установленные приложения**, найдите **Gemini Switcher** и нажмите **Удалить** (или запустите `uninstall.exe` из `%LOCALAPPDATA%\Programs\Gemini Switcher`). Деинсталлятор предложит удалить или сохранить пользовательские данные пула.
- Если использовалась portable-версия: завершите работу приложения через трей и удалите исполняемый файл вместе с папкой `%USERPROFILE%\.gemini-switcher`.
